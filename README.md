## 🚀 Installation

```bash
git clone git@github.com:Ludofr3/MyPortfolio.git
cd portfolio
npm install
npm run dev
```

### Configuration Required
- Create an [EmailJS](https://www.emailjs.com/) account for the contact form
- Configure API keys in the Contact.jsx file
